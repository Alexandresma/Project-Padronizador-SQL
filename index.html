Padronizador de comandos SQL

Envie um arquivo .sql ou .txt, escolha o banco de dados de origem e a ferramenta coloca todo comando e palavra-chave SQL em maiúsculo, mantendo o resto — nomes de tabela, colunas, aliases — em minúsculo.

Comandos são reconhecidos por uma lista de palavras-chave própria de cada banco (comandos, cláusulas, tipos de dado e funções nativas mais comuns). Scripts muito específicos podem conter termos fora dessa lista — revise o resultado antes de usar em produção.
